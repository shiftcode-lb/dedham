# Dedham Livery — Responsive React + Vite Website

Routes:
- `/` Home
- `/about` About
- `/services` Services
- `/contact` Contact / Booking
- `/safety` Safety + Terms & Policies

Run:
```bash
npm install
npm run dev
```

The layout uses fluid containers, CSS Grid/Flexbox, `clamp()` typography, and breakpoints at 1024px, 820px, 600px, and 380px. The mobile navbar uses a hamburger menu and locks background scrolling while open.
